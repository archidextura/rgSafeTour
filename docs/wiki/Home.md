# RGPia Web Service

여러 웹 서비스를 탭으로 모아 GitHub Pages로 게시하는 정적 사이트입니다. 첫 서비스는 **Safe Tour(서울 안심 도보길)** 입니다.

## 주소

- 사이트: https://archidextura.github.io/rgSafeTour/
- Safe Tour 탭: https://archidextura.github.io/rgSafeTour/#safe-tour
- 저장소: https://github.com/archidextura/rgSafeTour

앞으로의 모든 개선 작업은 `archidextura/rgSafeTour` 저장소에 저장합니다. (이전 저장소 `architektonike/rgSafeTour`에서 커밋 기록째 옮겨 왔습니다.)

## 배포

`main`에 푸시하면 `.github/workflows/pages.yml`이 사이트를 GitHub Pages로 배포합니다. 저장소 Settings → Pages → Source가 **GitHub Actions**로 되어 있어야 합니다.
