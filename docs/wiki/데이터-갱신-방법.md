# 데이터 갱신 방법

Safe Tour의 지도·관광지·CCTV 데이터는 `tools/safe-tour/build_data.py`로 다시 만듭니다.

## 1. 원본 받기

```bash
curl -LO https://download.bbbike.org/osm/bbbike/Seoul/Seoul.osm.pbf
```

CCTV는 공공데이터포털의 "전국CCTV표준데이터"에서 서울특별시 CSV를 내려받습니다.

## 2. 스크립트 실행

```bash
pip install osmium
python3 tools/safe-tour/build_data.py --pbf Seoul.osm.pbf --cctv <서울 CCTV 표준데이터.csv>
```

## 3. 결과 확인 후 커밋

`services/safe-tour/data/`에 다음 파일이 만들어집니다.

| 파일 | 내용 |
|---|---|
| `index.json` | 데이터 목록·메타정보 |
| `places.json` | 관광지와 소속 구 |
| `districts.json` | 25개 구 경계 |
| `areas-large.json` | 한강·큰 공원 |
| `tiles/*.json` | 2km 격자별 보행 도로망·작은 녹지·CCTV |

관광지는 OSM에서 이름과 위키데이터가 있는 궁궐·박물관·미술관·명소·공원·시장 등과, 스크립트의 `CURATED` 목록(명동·인사동·홍대 거리 등)을 씁니다. 관광지가 8곳보다 적은 구는 위키데이터가 없는 큰 공원·박물관·명소·시장으로 채웁니다.

로컬에서 확인(`python3 -m http.server 0 --bind 127.0.0.1`)한 뒤 작업 브랜치에 커밋하고 `main`으로 PR을 올리면, 병합 시 자동으로 배포됩니다.
