# 서비스 추가 방법

## 구조

```
index.html            탭 셸 (상단 바 + 서비스 프레임)
services.js           서비스 목록 – 탭은 여기서 만들어집니다
assets/               셸 스타일·스크립트
services/<id>/        서비스별 독립 페이지
tools/<id>/           서비스 데이터 생성 스크립트
```

## 3단계

1. `services/<id>/index.html`에 독립적으로 동작하는 페이지를 만듭니다.
2. `services.js`의 `RGPIA_SERVICES` 배열에 항목을 추가합니다.

   ```js
   { id: 'my-service', label: 'My Service', title: '서비스 이름', path: 'services/my-service/', description: '한 줄 설명' }
   ```

   위치 권한 등이 필요하면 `allow` 값을 줍니다(예: Safe Tour의 `allow: 'geolocation'`).
3. 로컬에서 확인한 뒤 `main`으로 PR을 올립니다. 병합되면 `https://archidextura.github.io/rgSafeTour/#my-service`로 열립니다.

각 서비스는 별도 프레임에서 열리므로 스타일과 스크립트가 서로 섞이지 않습니다. `.github/workflows/pages.yml`은 `index.html services.js assets services .nojekyll`만 배포하므로, 새 최상위 폴더를 쓰려면 이 목록에도 추가해야 합니다.
